# تحديث تبويبات تعليقات Meta

**التاريخ:** 18 أغسطس 2026  
**النطاق:** تبويبا «تعليقات فيسبوك» و«تعليقات Instagram» في صندوق البريد الموحد.

## القرار التصميمي

لم تعد تبويبات التعليقات تستخدم واجهة المحادثة الخاصة بالرسائل. تعرض الواجهة الآن **سياقات المحتوى الأصلي**: منشور Facebook أو وسيط Instagram، ثم سلسلة التعليقات والردود المتفرعة المرتبطة به. يبقى تبويب «كل الرسائل» مخصصاً لرسائل Messenger وInstagram المباشرة فقط، بما يتسق مع المرجع المرفق وسلوك صندوق Meta Business.

| الطبقة | ما تم تنفيذه |
|---|---|
| التطبيع | إضافة سياق المصدر (`facebook_post` أو `instagram_media`) ومعرّفه ورابطه ومعاينته ونوعه، إلى جانب الإعجابات والردود والإخفاء والخصوصية وصلاحيات الرد. |
| التخزين | إضافة `commentContext` لسياق المنشور/الوسيط و`commentMetadata` للبيانات التشغيلية لكل تعليق، عبر ترحيل غير مدمر. |
| الاستعلام | إضافة `socialInbox.commentContexts` الذي يعيد سياقات التعليقات مع عناصرها المرتبة، مستقلة عن استعلامات محادثات الرسائل. |
| الواجهة | قائمة لسياقات المنشورات أو الوسائط، بطاقة للمصدر، شجرة ردود متفرعة، عدادات التفاعل، حالات الإخفاء/الخصوصية، وفلاتر الكل/غير المقروء/متابعة. |
| الإجراءات | تُعرض «رد»، «رسالة خاصة»، و«إخفاء/إظهار» عندما تسمح البيانات. الإرسال والتعديل ما زالا واضحين كإجراءات تتطلب موصل Meta رسمي قبل تنفيذ أي طلب خارجي. |

## مطابقة الحقول الرسمية

تعتمد بنية Instagram على حقول `media` و`parent_id` و`text` و`like_count` و`hidden` وعلى ردود التعليقات، وهي الحقول التي تعرّف المصدر والعلاقة الهرمية وحالة التعليق. [1] كما تستفيد بطاقة الوسيط من `caption` و`media_type` و`media_url` أو `thumbnail_url` و`permalink` عندما تكون متاحة. [2]

أما Facebook فيُستخدم `parent` أو `parent_id` لبناء الردود، و`comment_count` و`like_count` و`can_comment` و`can_reply_privately` و`is_private` لتحديد العرض والإجراءات المتاحة. [3] [4] تعرض واجهة المنشور الرابط الدائم والمعاينة والمحتوى عندما تتوفر حقول المنشور مثل `permalink_url` و`full_picture` و`message`. [5]

> **ملاحظة تشغيلية:** لا تضم جميع Webhooks معاينة المنشور أو الوسيط الكاملة دائماً. تحتفظ المنظومة بالحدث الخام وتستخدم الحقول المتاحة؛ ويمكن في مرحلة لاحقة إضافة إثراء خادمي محدود عبر Graph API عندما يكون Page Access Token والصلاحيات اللازمة مفعّلين.

## التحقق

اجتازت الاختبارات المركزة **16/16**، وتشمل تطبيع سياق Facebook وInstagram، وحفظ البيانات في قاعدة البيانات، وشجرة تعليقات Facebook، وسياق وسيط Instagram مع رد متفرع بواسطة `parent_id` في الواجهة. نجح `pnpm run check` ونجح `pnpm run build`.

نفّذ Vitest الكامل **934** اختباراً؛ نجح **926**، وبقيت **8** إخفاقات سابقة وغير مرتبطة بهذا التغيير في ثلاثة ملفات: اختبار ترخيص البيئة، واختبارات مسارات المخيمات عند غياب قاعدة البيانات، واختبارا حدود SEO اللذان يحتويان قيماً مخالفة للشروط التي يختبرانها.

## تجربة البيانات المنشورة

بيانات Meta التجريبية الحالية أُدخلت قبل إضافة حقول السياق الجديدة. بعد نشر هذه النسخة، استخدم المسؤول من **إعدادات ربط Meta** إجراء **تنظيف بيانات الاختبار** ثم **إدخال بيانات الاختبار** لإعادة إنشاء العينات الغنية بسياق المنشور والوسيط داخل الواجهة الجديدة. لا يحذف هذا الإجراء إلا الحسابات والأحداث الموسومة للاختبار.
