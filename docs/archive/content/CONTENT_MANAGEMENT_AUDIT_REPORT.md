## الفجوات والأخطاء الحرجة

### 1. **مشكلة حقل `status` في جميع الـ schemas** ⚠️ **حرج** ✅ **تم الحل**

**الوصف:**
- جميع الجداول في قاعدة البيانات تحتوي على حقل `status` (draft, published, archived)
- لكن الـ schemas في الـ routers لا تتضمن هذا الحقل
- هذا يعني أن جميع المحتوى سيكون بـ `draft` افتراضياً ولن يمكن نشره

**الملفات المتأثرة:**
- `/server/routers/content/pages.ts` - `pageSchema` لا يحتوي على `status` ✅ تم الإصلاح
- `/server/routers/content/sections.ts` - `sectionSchema` لا يحتوي على `status` ✅ تم الإصلاح
- `/server/routers/content/textContent.ts` - `textContentSchema` لا يحتوي على `status` ✅ تم الإصلاح
- `/server/routers/content/images.ts` - `imageSchema` لا يحتوي على `status` ✅ تم الإصلاح

**التأثير:**
- لا يمكن نشر المحتوى في الواجهات العامة
- المحتوى سيبقى دائماً في حالة المسودة
- فلتر `status` في الواجهات العامة لن يعمل بشكل صحيح

**الحل المطلوب:**
إضافة حقل `status` إلى جميع الـ schemas:
```typescript
status: z.enum(['draft', 'published', 'archived']).default('draft')
```

**الحالة:** ✅ تم التنفيذ - تم إضافة حقل `status` و `publishedAt` إلى جميع الـ schemas

---

### 2. **مشكلة حقل `publishedAt`** ⚠️ **متوسط** ✅ **تم الحل**

**الوصف:**
- جميع الجداول تحتوي على حقل `publishedAt`
- لكن لا يتم تعيينه عند تغيير الحالة إلى `published`
- لا يوجد منطق لتعيين هذا الحقل تلقائياً

**التأثير:**
- لا يمكن تتبع تاريخ النشر الفعلي
- لا يمكن عمل تقارير عن المحتوى المنشور حسب التاريخ

**الحل المطلوب:**
إضافة منطق لتعيين `publishedAt` عند تغيير الحالة إلى `published`:
```typescript
publishedAt: input.status === 'published' ? new Date() : undefined
```

**الحالة:** ✅ تم التنفيذ - تم إضافة منطق تعيين `publishedAt` تلقائياً في جميع الـ create و update mutations

---

### 3. **مشكلة الحذف الناعم (Soft Delete)** ⚠️ **حرج** ✅ **تم الحل**

**الوصف:**
- جميع الجداول تحتوي على حقل `deletedAt` للحذف الناعم
- لكن الـ routers تقوم بحذف حقيقي باستخدام `db.delete()`
- لا يوجد منطق للحذف الناعم (تعيين `deletedAt` بدلاً من الحذف)

**الملفات المتأثرة:**
- `/server/routers/content/pages.ts` - `delete` mutation ✅ تم الإصلاح
- `/server/routers/content/sections.ts` - `delete` mutation ✅ تم الإصلاح
- `/server/routers/content/textContent.ts` - `delete` mutation ✅ تم الإصلاح
- `/server/routers/content/images.ts` - `delete` mutation ✅ تم الإصلاح

**التأثير:**
- فقدان البيانات نهائياً عند الحذف
- لا يمكن استعادة المحتوى المحذوف
- لا يمكن عمل سجل للمحتوى المحذوف

**الحل المطلوب:**
تغيير منطق الحذف من الحذف الحقيقي إلى الحذف الناعم:
```typescript
await db.update(table).set({ deletedAt: new Date() }).where(eq(table.id, input.id))
```

**الحالة:** ✅ تم التنفيذ - تم تغيير جميع delete mutations إلى حذف ناعم
