# وثيقة تصميم نظام إدارة الصفحات والأقسام
## Pages and Sections Management System Design Document

---

## 1. نظرة عامة (Overview)

يهدف هذا النظام إلى توفير إدارة شاملة ومرنة لمحتوى الموقع من خلال هيكلية هرمية تربط الصفحات بالأقسام، مما يسهل إدارة المحتوى وتنظيمه بشكل منطقي وسهل الصيانة.

### الأهداف الرئيسية:
- **إدارة صفحات الموقع بشكل ديناميكي**: إمكانية إضافة وتعديل وحذف الصفحات دون الحاجة لتعديل الكود
- **تنظيم المحتوى هرمياً**: ربط الصفحات بالأقسام والأقسام بالمحتوى (نصوص، صور، أزرار)
- **دعم الصفحات الرئيسية والفرعية**: هيكلية شجرة للصفحات مع إمكانية الربط بينها
- **إدارة SEO متقدمة**: تحسين محركات البحث لكل صفحة بشكل منفصل
- **واجهة إدارة سهلة الاستخدام**: أدوات سحب وإفلات للترتيب، فلاتر متقدمة، بحث سريع

## 2. هيكل قاعدة البيانات المقترح (Database Schema)

### 2.1 جدول الصفحات (pages)

```typescript
interface Page {
  id: number;
  name: string;                    // اسم الصفحة (للعرض في لوحة الإدارة)
  slug: string;                    // رابط الصفحة (URL-friendly)
  type: 'main' | 'sub';            // نوع الصفحة: رئيسية أو فرعية
  parentId?: number;               // معرف الصفحة الرئيسية (إذا كانت فرعية)
  titleAr: string;                 // العنوان الرئيسي بالعربية
  titleEn: string;                 // العنوان الرئيسي بالإنجليزية
  metaTitleAr: string;             // عنوان الرأس SEO بالعربية
  metaTitleEn: string;             // عنوان الرأس SEO بالإنجليزية
  metaDescriptionAr: string;       // وصف SEO بالعربية
  metaDescriptionEn: string;       // وصف SEO بالإنجليزية
  keywordsAr: string;              // الكلمات المفتاحية بالعربية
  keywordsEn: string;              // الكلمات المفتاحية بالإنجليزية
  isActive: 'yes' | 'no';          // حالة الصفحة: نشطة أو معطلة
  sortOrder: number;               // ترتيب الصفحة
  createdAt: Date;
  updatedAt: Date;
}
```

### 2.2 جدول الأقسام (sections)

```typescript
interface Section {
  id: number;
  pageId: number;                  // معرف الصفحة المرتبطة
  name: string;                    // اسم القسم (للعرض في لوحة الإدارة)
  titleAr: string;                 // عنوان القسم بالعربية
  titleEn: string;                 // عنوان القسم بالإنجليزية
  subtitleAr: string;              // العنوان الفرعي بالعربية
  subtitleEn: string;              // العنوان الفرعي بالإنجليزية
  type: SectionType;              // نوع القسم (انظر أدناه)
  sortOrder: number;               // ترتيب القسم داخل الصفحة
  isActive: 'yes' | 'no';          // حالة القسم: نشط أو معطل
  createdAt: Date;
  updatedAt: Date;
}

type SectionType = 
  | 'slider'           // سلايدر (صور متعددة مع نصوص)
  | 'text'             // نصوص فقط
  | 'text-cards'       // بطاقات نصوص
  | 'stats-cards'      // بطاقات إحصائيات
  | 'image-cards'      // بطاقات صور متعددة
  | 'image'            // صورة واحدة
  | 'video'            // فيديو
  | 'hero'             // قسم رئيسي
  | 'cta'              // دعوة للإجراء
  | 'features'         // ميزات
  | 'testimonials'     // شهادات العملاء
  | 'faq'              // أسئلة شائعة
  | 'contact'          // نموذج تواصل
  | 'pricing'          // أسعار
  | 'team'             // فريق العمل
  | 'gallery'          // معرض صور
  | 'timeline'         // جدول زمني
  | 'custom';          // مخصص
```

### 2.3 جدول أزرار الأقسام (section_buttons)

```typescript
interface SectionButton {
  id: number;
  sectionId: number;                // معرف القسم المرتبط
  textAr: string;                  // نص الزر بالعربية
  textEn: string;                  // نص الزر بالإنجليزية
  link: string;                    // رابط الزر
  style: 'primary' | 'secondary' | 'outline' | 'ghost'; // نمط الزر
  sortOrder: number;               // ترتيب الزر
  isActive: 'yes' | 'no';          // حالة الزر: نشط أو معطل
  createdAt: Date;
  updatedAt: Date;
}
```

### 2.4 تحديث جدول النصوص (text_content)

```typescript
interface TextContent {
  id: number;
  key: string;                     // مفتاح فريد (مثال: home.hero.title.ar)
  language: 'ar' | 'en';           // اللغة
  content: string;                 // المحتوى النصي
  sectionId?: number;              // معرف القسم المرتبط (جديد)
  pageId: number;                  // معرف الصفحة المرتبطة (جديد)
  type: ContentType;               // نوع المحتوى
  isActive: 'yes' | 'no';          // حالة النص: نشط أو معطل
  createdAt: Date;
  updatedAt: Date;
}

type ContentType = 
  | 'title'            // عنوان
  | 'subtitle'         // عنوان فرعي
  | 'description'      // وصف
  | 'text'             // نص عادي
  | 'button'           // نص زر
  | 'link'             // نص رابط
  | 'label'            // تسمية
  | 'placeholder'      // نص placeholder
  | 'error'            // رسالة خطأ
  | 'success'          // رسالة نجاح
  | 'warning'          // رسالة تحذير
  | 'info';            // رسالة معلومات
```

### 2.5 تحديث جدول الصور (images)

```typescript
interface Image {
  id: number;
  key: string;                     // مفتاح فريد (مثال: home.hero.image.ar)
  url: string;                     // رابط الصورة
  altAr: string;                   // نص بديل بالعربية
  altEn: string;                   // نص بديل بالإنجليزية
  sectionId?: number;              // معرف القسم المرتبط (جديد)
  pageId: number;                  // معرف الصفحة المرتبطة (جديد)
  width?: number;                  // عرض الصورة
  height?: number;                 // ارتفاع الصورة
  format: string;                   // صيغة الصورة (jpg, png, webp)
  size: number;                    // حجم الصورة بالبايت
  isActive: 'yes' | 'no';          // حالة الصورة: نشطة أو معطلة
  createdAt: Date;
  updatedAt: Date;
}
```

## 3. واجهة المستخدم المقترحة (UI Design)

### 3.1 تبويب الصفحات (Pages Tab)

#### 3.1.1 قائمة الصفحات الرئيسية
- **جدول عرض الصفحات** يحتوي على:
  - اسم الصفحة
  - نوع الصفحة (رئيسية/فرعية)
  - رابط الصفحة (slug)
  - الحالة (نشط/معطل)
  - الترتيب
  - تاريخ الإنشاء
  - تاريخ التحديث
  - أزرار الإجراءات (تعديل، حذف، عرض)

#### 3.1.2 إضافة/تعديل صفحة
**النموذج يحتوي على:**

**البيانات الأساسية:**
- اسم الصفحة (للعرض في لوحة الإدارة)
- نوع الصفحة (رئيسية/فرعية)
- الصفحة الرئيسية (إذا كانت فرعية) - قائمة منسدلة
- رابط الصفحة (slug) - مع التحقق من التكرار
- الحالة (نشط/معطل)
- الترتيب (رقم)

**بيانات SEO بالعربية:**
- العنوان الرئيسي (titleAr)
- عنوان الرأس (metaTitleAr)
- وصف SEO (metaDescriptionAr)
- الكلمات المفتاحية (keywordsAr) - مفصولة بفواصل

**بيانات SEO بالإنجليزية:**
- العنوان الرئيسي (titleEn)
- عنوان الرأس (metaTitleEn)
- وصف SEO (metaDescriptionEn)
- الكلمات المفتاحية (keywordsEn) - مفصولة بفواصل

#### 3.1.3 مربع إدارة الأقسام
- **قائمة الأقسام المرتبطة بالصفحة** مع:
  - اسم القسم
  - نوع القسم
  - الترتيب
  - الحالة
  - أزرار الإجراءات
- **ميزة السحب والإفلات** لترتيب الأقسام
- **زر إضافة قسم جديد** يفتح نافذة منبثقة لإضافة قسم
- **زر ربط قسم موجود** يفتح قائمة بالأقسام غير المرتبطة

### 3.2 تبويب الأقسام (Sections Tab)

#### 3.2.1 قائمة الأقسام
- **جدول عرض الأقسام** يحتوي على:
  - اسم القسم
  - الصفحة المرتبطة
  - نوع القسم
  - الحالة
  - الترتيب
  - تاريخ الإنشاء
  - تاريخ التحديث
  - أزرار الإجراءات

#### 3.2.2 الفلاتر والبحث
- **بحث** بالاسم أو العنوان
- **فلتر الصفحة** - قائمة منسدلة بجميع الصفحات
- **فلتر نوع القسم** - قائمة منسدلة بجميع أنواع الأقسام
- **فلتر الحالة** - نشط/معطل/الكل

#### 3.2.3 إضافة/تعديل قسم
**النموذج يحتوي على:**

**البيانات الأساسية:**
- اسم القسم (للعرض في لوحة الإدارة)
- الصفحة المرتبطة - قائمة منسدلة
- نوع القسم - قائمة منسدلة
- الحالة (نشط/معطل)
- الترتيب (رقم)

**العناوين بالعربية:**
- عنوان القسم (titleAr)
- العنوان الفرعي (subtitleAr)

**العناوين بالإنجليزية:**
- عنوان القسم (titleEn)
- العنوان الفرعي (subtitleEn)

**إدارة الأزرار:**
- قائمة الأزرار المرتبطة بالقسم
- إضافة زر جديد
- تعديل/حذف أزرار موجودة
- ترتيب الأزرار بالسحب والإفلات

**بيانات الزر:**
- نص الزر بالعربية
- نص الزر بالإنجليزية
- رابط الزر
- نمط الزر (primary/secondary/outline/ghost)
- الترتيب
- الحالة

### 3.3 تبويب النصوص (Text Content Tab)

#### 3.3.1 الفلاتر المحسنة
- **بحث** بالمفتاح أو المحتوى
- **فلتر الصفحة** - قائمة منسدلة بجميع الصفحات
- **فلتر القسم** - قائمة منسدلة بأقسام الصفحة المحددة (ديناميكية)
- **فلتر اللغة** - عربي/إنجليزي/الكل
- **فلتر نوع المحتوى** - قائمة منسدلة بجميع أنواع المحتوى
- **فلتر الحالة** - نشط/معطل/الكل

#### 3.3.2 إضافة/تعديل نص
**النموذج يحتوي على:**
- المفتاح (key) - مع التحقق من التكرار
- اللغة
- المحتوى النصي
- الصفحة المرتبطة - قائمة منسدلة
- القسم المرتبط - قائمة منسدلة (تعتمد على الصفحة المحددة)
- نوع المحتوى
- الحالة

### 3.4 تبويب الصور (Images Tab)

#### 3.4.1 الفلاتر المحسنة
- **بحث** بالمفتاح أو اسم الصورة
- **فلتر الصفحة** - قائمة منسدلة بجميع الصفحات
- **فلتر القسم** - قائمة منسدلة بأقسام الصفحة المحددة (ديناميكية)
- **فلتر الصيغة** - jpg/png/webp/الكل
- **فلتر الحالة** - نشط/معطل/الكل

#### 3.4.2 إضافة/تعديل صورة
**النموذج يحتوي على:**
- المفتاح (key) - مع التحقق من التكرار
- رفع الصورة (مع معاينة)
- النص البديل بالعربية
- النص البديل بالإنجليزية
- الصفحة المرتبطة - قائمة منسدلة
- القسم المرتبط - قائمة منسدلة (تعتمد على الصفحة المحددة)
- الحالة

## 4. الميزات والوظائف الإضافية المقترحة

### 4.1 ميزات إدارة الصفحات
- **معاينة الصفحة**: زر لمعاينة الصفحة قبل النشر
- **نسخ صفحة**: إنشاء نسخة من صفحة موجودة
- **أرشفة الصفحات**: إمكانية أرشفة الصفحات بدلاً من حذفها نهائياً
- **تاريخ التغييرات**: سجل لتغييرات الصفحة مع إمكانية التراجع
- **نشر مجدول**: إمكانية جدولة نشر الصفحة في تاريخ محدد
- **قوالب الصفحات**: إنشاء قوالب جاهزة للصفحات الشائعة

### 4.2 ميزات إدارة الأقسام
- **قوالب الأقسام**: قوالب جاهزة لأنواع الأقسام المختلفة
- **نسخ قسم**: إنشاء نسخة من قسم موجود
- **معاينة القسم**: معاينة كيف يظهر القسم في الصفحة
- **إعدادات مخصصة لكل نوع**: إعدادات إضافية حسب نوع القسم
  - Slider: عدد الشرائح، سرعة التمرير، تأثيرات الانتقال
  - Video: رابط الفيديو، خيارات التشغيل التلقائي
  - Stats Cards: عدد الأعمدة، الألوان، الأيقونات

### 4.3 ميزات إدارة المحتوى
- **تحرير بصري**: محرر WYSIWYG للنصوص
- **رفع جماعي**: رفع صور متعددة دفعة واحدة
- **تحسين الصور**: ضغط وتحسين الصور تلقائياً عند الرفع
- **استيراد/تصدير**: استيراد وتصدير المحتوى بصيغة JSON
- **ترجمة تلقائية**: اقتراح ترجمة تلقائية للنصوص
- **التحقق من الروابط**: التحقق من صحة الروابط في الأزرار

### 4.4 ميزات عامة
- **إشعارات**: إشعارات للتغييرات والتحديثات
- **سجل النشاطات**: سجل لجميع العمليات المنفذة
- **صلاحيات المستخدمين**: إدارة صلاحيات الوصول للمحتوى
- **نسخ احتياطي تلقائي**: نسخ احتياطي دوري للمحتوى
- **استعادة النسخ الاحتياطية**: استعادة المحتوى من نسخ احتياطية

## 8. الخلاصة

هذا النظام سيوفر إدارة شاملة ومرنة لمحتوى الموقع، مما يسهل على المسؤولين إدارة الصفحات والأقسام والمحتوى بشكل منظم وفعال. الهيكلية الهرمية المقترحة تربط جميع العناصر ببعضها البعض، مما يسهل التنقل والإدارة.

النظام مصمم ليكون قابل للتوسع، حيث يمكن إضافة أنواع جديدة من الأقسام والمحتوى بسهولة في المستقبل دون الحاجة لتعديل البنية الأساسية.
