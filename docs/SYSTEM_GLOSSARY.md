# قاموس مصطلحات النظام

**الحالة:** `working`  
**المجال:** Overview  
**آخر مراجعة:** 2026-09-11

| المصطلح | التعريف المعتمد |
|---|---|
| BOCAM CRM | الاسم المعتمد للمشروع في وثائق النظام الحالية |
| SGH CRM Portal | اسم تاريخي أو تجاري يظهر في بعض الملفات القديمة |
| CRM | وظائف إدارة العملاء والحملات والحجوزات والعمليات الداخلية |
| CMS | إدارة الصفحات والأقسام والنصوص والوسائط والنشر والمعاينات |
| Lead | سجل عميل محتمل مرتبط بمصدر أو حملة أو عملية متابعة |
| Patient | مستخدم أو سجل مريض له بيانات مواعيد ونتائج وملف شخصي |
| Appointment | موعد طبي تديره الإدارة أو بوابة المريض وله حالات وتذكيرات |
| Campaign | مبادرة تسويقية تربط أهدافًا وميزانية ومصادر وعناصر مرتبطة |
| Offer | عرض طبي أو تسويقي يمكن عرضه وتسجيل العملاء عليه |
| Camp | مخيم أو فعالية طبية لها تسجيلات وإدارة مستقلة |
| Social Inbox | استقبال وإدارة تفاعلات اجتماعية واردة داخل النظام |
| Social Publishing | إعداد وتسليم ونشر محتوى إلى منصات خارجية |
| Integration | اتصال مع خدمة أو منصة خارجية مثل Meta أو WhatsApp أو التخزين |
| Router | مجموعة إجراءات tRPC أو مسارات منطقية داخل `server/routers/` |
| Procedure | إجراء tRPC مفرد يحدد الإدخال والإخراج والحماية والتنفيذ |
| Service | وحدة منطق أعمال أو تكامل مساعدة للراوترات والمهام |
| Webhook | طلب HTTP وارد من منصة خارجية لمعالجة حدث |
| SSE | Server-Sent Events لبث تحديثات من الخادم إلى العميل |
| Job | مهمة مجدولة أو مؤجلة، غالبًا ضمن `server/tasks/` أو scheduled routes |
| PWA | نسخة تطبيق ويب قابلة للتثبيت مع حالات تشغيل دون اتصال |
| Feature gate | حاجز وصول يعتمد على ميزة أو ترخيص قبل عرض صفحة أو وظيفة |
| Admin shell | التخطيط الإداري الذي يحتوي صفحات `/admin/*` |
| Patient portal | الواجهة ومسارات `/patient-portal/*` الخاصة بالمريض |
| Public page | صفحة لا تنتمي إلى لوحة الإدارة أو بوابة المريض |

## قواعد استخدام المصطلحات

- يستخدم BOCAM CRM في العناوين الجديدة، ويذكر SGH CRM Portal عند شرح التوافق التاريخي.
- لا يستخدم CMS للإشارة إلى CRM أو العكس.
- لا يستخدم Social Inbox كمرادف لـ WhatsApp؛ هما مجالان متكاملان لكن منفصلان.
- لا يستخدم Router للإشارة إلى REST route دون توضيح نوع الواجهة.
- لا يعلن عن ميزة كـ current إلا إذا رُبطت بمصدر في مصفوفة التغطية.
