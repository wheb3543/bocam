**الحالة:** مكتملة ضمن نطاق التوثيق

## 1. نطاق التنفيذ

تمت مراجعة وتحديث توثيق الترخيص وحماية التشغيل دون تعديل آليات التوقيع أو Hardware ID أو heartbeat أو صلاحيات license router.

## 3. الحقائق الموثقة

- التحقق المحلي يستخدم RSA-PSS مع SHA-256 ومفاتيح عامة حالية وسابقة.
- التحقق يفحص Hardware ID والانتهاء والميزات، ويفحص النطاق عند ضبط متغيراته.
- `initializeLicense(true)` يسمح activation mode عند غياب الملف.
- `validateLicense` يعيد معلومات غير صالحة في حالات الفشل المعتادة؛ Kill Switch العام غير مثبت كسلوك دائم.
- Feature Middleware وFeature Gate منفصلان عن RBAC.
- heartbeat يستخدم `IDEA_HUB_URL` ويفشل بصمت عند أخطاء الشبكة.
- السجلات المحلية تحتفظ بآخر 30 سجل heartbeat، وملفات الطلبات المؤقتة تستخدم `0600` والاستبدال الذري.
- إجراءات license العامة وطلبات التفعيل قبل تسجيل الدخول موثقة كقرار مراجعة أمني، دون تغيير سلوكها.

الاختبارات تثبت الوحدات التي تغطيها فقط، ولا تثبت heartbeat إنتاجيًا أو الامتثال القانوني أو Kill Switch عامًا.

## 5. القيود والقرارات المؤجلة

- قرار فرض إيقاف الخادم عند الترخيص غير الصالح خارج نطاق التوثيق ويحتاج موافقة أمنية مستقلة.
- سياسة Hardware ID للحاويات والأجهزة الافتراضية تحتاج قرار تشغيل.
- مقدار البيانات التي تعرضها إجراءات الترخيص العامة يحتاج مراجعة أمنية.
- ملكية المكونات والامتثال HIPAA/GDPR يحتاجان مراجعة قانونية مستقلة.
