## 3. القرارات المطبقة

- اعتماد Node.js `>=22.13.0` وpnpm `>=10.4.0` وفق المشروع وDocker.
- فصل تشغيل Node المحلي عن Docker Compose الذي يوفر MySQL.
- استخدام اسم خدمة `mysql` داخل `DATABASE_URL` عند التشغيل داخل Compose.
- توضيح أن `check-env` يفحص ثلاثة متغيرات أساسية فقط ولا يثبت جاهزية كل التكاملات.
- فصل المتغيرات الأساسية عن متغيرات الميزات الاختيارية وأسرار النشر.
- إزالة ادعاءات Quick Start القديمة مثل `/patient` واستبدالها بـ`/patient-portal/login`.
- عدم اعتبار أمثلة Mock القديمة دليلًا على تفعيل كل خدمات المحاكاة.

## 5. القيود والملاحظات

- ظهر أثناء `pnpm build` تحذير Vite متعلق بقيمة `NODE_ENV=production` في ملف البيئة؛ البناء اكتمل بنجاح، ولم تُعدل ملفات البيئة.
- لم تُشغل حاويات Docker أو أوامر Drizzle التي تحتاج قاعدة بيانات فعلية، لعدم توفر بيئة تشغيل آمنة ومعلومات اتصال معتمدة ضمن نطاق هذه الجولة.
- لم يُشغل `pnpm start` لتجنب تشغيل خدمة طويلة الأمد في جلسة التحقق.
- اختلاف أسماء بعض متغيرات Meta وWhatsApp بقي موثقًا، وتفاصيل ملكيتها النهائية تراجع في مراحل التكامل.
