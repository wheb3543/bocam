## 3. الحقائق الموثقة

- يوجد مسار مصادقة محلي username/password ومسار OAuth/Manus.
- `context.ts` يجرب الجلسة المحلية ثم OAuth.
- تختلف أسرار وبنية وخصائص Cookie بين المسارين، وسجل ذلك كقرار أمني مؤجل.
- توجد طبقات `protectedProcedure` و`adminProcedure` و`permissionProcedure`.
- قرار RBAC يمر عبر admin ثم assignment مخصص ثم system role ثم fallback افتراضي.
- توجد خريطة توافق legacy للصلاحيات الإدارية القديمة.
- `ProtectedRoute` و`useLicense` حواجز ترخيص واجهة منفصلة عن RBAC.
- وثقت الفجوة في `auth.updateProfile` دون إصلاحها خارج النطاق.

## 5. ملاحظة اختبار خارج النطاق

فشل اختبار واحد غير متعلق بتغييرات المرحلة:

```text
client/src/__tests__/dashboardWorkspace.test.tsx
Dashboard operational workspace > prioritizes daily operations and remains useful when analytics are unavailable
Unable to find link named /صندوق البريد/
```

لم يتم تعديل هذا الاختبار أو الواجهة لأنه خارج نطاق الهوية والصلاحيات. يجب مراجعته في مرحلة الواجهة أو الاختبارات.

## 6. الفجوات والقرارات المؤجلة

- اختلاف أسرار وخصائص جلسات local/OAuth يحتاج قرارًا أمنيًا مستقلًا.
- `auth.updateProfile` يستخدم `publicProcedure` مع فحص يدوي؛ سجل كمرشح إصلاح.
- بعض الصلاحيات قد تكون غير مستخدمة أو محمية عبر دوال مشتركة؛ التفصيل يستكمل في مراحل المجالات.
- ادعاءات CSRF و2FA والامتثال في وثائق الأمان لا تعتبر مثبتة بالكامل دون مصادر تنفيذ واختبار مستقلة.
