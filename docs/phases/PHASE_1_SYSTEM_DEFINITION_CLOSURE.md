## 3. القرارات المطبقة

- استخدام BOCAM CRM كاسم المشروع الحالي، مع إبقاء SGH CRM Portal كاسم تاريخي/تجاري.
- اعتبار النظام متعدد الواجهات: عامة، إدارة، بوابة مريض، ومسارات نظامية.
- توثيق الخادم كنظام Express هجين يضم tRPC وREST وOAuth وWebhooks وSSE وscheduled routes وSwagger.
- عدم استخدام أعداد ثابتة للصفحات أو الراوترات عندما لا تكون مصدرًا قابلًا للتوليد.
- إبقاء تفاصيل API وRBAC وCMS وWhatsApp وقاعدة البيانات لمراحلها المتخصصة.

## 5. الملاحظات المؤجلة

- تفاصيل الصلاحيات وحواجز الميزات ستوثق في المرحلة 3.
- تفاصيل التثبيت ومتغيرات البيئة ستوثق في المرحلة 2.
- تفاصيل API وقاعدة البيانات والتكاملات ستوثق في مراحلها المتخصصة.
- تكرار تعريف مسارات الإدارة في الكود تم توثيقه كسياق، ولم يُصلح لأنه خارج نطاق التوثيق.
- عدد السجلات قد يتغير بعد إضافة تقرير الإغلاق؛ يجب إعادة تشغيل `pnpm docs:check` بعد أي إضافة وثائق.
