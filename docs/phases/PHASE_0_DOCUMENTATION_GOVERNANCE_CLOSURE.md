## 5. البنود المؤجلة والمحدوديات

- لم تُصنف كل وثيقة إلى `canonical`؛ السجل يستخدم `unclassified` أو `working` حتى تراجعها مرحلة المجال.
- حقول `owner` و`source_code_paths` و`test_paths` في السجل تحتاج تعبئة دقيقة أثناء مراحل المجالات.
- لم يتم دمج أو أرشفة أي وثيقة متكررة، وسجل التعارضات يحفظ القرارات المطلوبة.
- فحص الروابط الخارجية يعتمد على GitHub Action، ولم يُنفذ اتصال خارجي من البيئة المحلية.
- لم تُنشأ بعد قواعد تلقائية لاكتشاف تغييرات API أو schema؛ ستراجع في مراحل API والبيانات والاستدامة.
